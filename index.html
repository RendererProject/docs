How to use Renderer

مدل سه‌بعدی را در مرورگر باز کنید، نور را جابه‌جا کنید، کیفیت را عوض کنید، کولیدرها را مخفی کنید و تصویر یا فرمت‌های دیگر بگیرید. روی موبایل و رایانه کار می‌کند.

Open 3D models in the browser, move the light, change quality, hide colliders, and export images or other formats. Works on phone and PC.

اجرای Renderer Launch Renderer از اینجا شروع کنید Start here

باز کردن مدل Open a model

منوی فایل

File menu

از فایل ← باز کردن… (یا Ctrl+O) مدل را از دستگاه خود انتخاب کنید.

Choose File → Open… (or Ctrl+O) and pick a model from your device.

کشیدن و رها کردن

Drag and drop

فایل (یا پوشه / زیپ) را روی ناحیه تیرهٔ نما بیندازید.

Drop a file (or a folder/zip) onto the dark viewport area.

مدل نمونه

Sample model

از فایل ← باز کردن مدل نمونه یا دکمهٔ صفحهٔ خالی استفاده کنید.

Use File → Open sample model or the button on the empty screen.

فرمت‌های رایج Common formats

glTF / GLB، OBJ (+ MTL)، FBX، COLLADA (DAE)، STL، PLY، 3DS، 3MF و RenderWare DFF / TXD (سبک GTA). بافت‌های کنار مدل با باز کردن زیپ یا چند فایل با هم بارگذاری می‌شوند.

glTF / GLB, OBJ (+ MTL), FBX, COLLADA (DAE), STL, PLY, 3DS, 3MF, and RenderWare DFF / TXD (GTA-style). Textures next to the model load when you open a zip or drop several files together.

ماشین‌های خیلی بزرگ روی موبایل ممکن است کند باشند. کیفیت Path ← کم یا خاموش را انتخاب کنید. Large cars can be slow on phones. Prefer Path quality → Low or Off.

چرخاندن و نگاه کردن Look around

  • چرخش دوربین — کشیدن با دکمهٔ چپ روی فضای خالی.
  • جابه‌جایی — دکمهٔ راست (یا دو انگشت روی لمسی).
  • زوم — چرخ ماوس یا نیشگون.
  • چرخش خود مدل — نمایش ← چرخش مدل (یا M)، سپس مدل را بکشید.
  • چرخش دقیق — نمایش ← چرخش به‌اندازه… برای ۹۰° / ۱۸۰° یا بازنشانی.
  • چرخش خودکار — نمایش ← چرخش خودکار (A).
  • سیم‌نما — نمایش ← سیم‌نما (W).
  • Rotate camera — left-drag on empty space.
  • Pan — right-drag (or two-finger drag on touch).
  • Zoom — scroll wheel or pinch.
  • Rotate the model — View → Rotate model (or M), then drag.
  • Snap rotate — View → Rotate by… for 90° / 180° or reset.
  • Auto-rotate — View → Auto-rotate (A).
  • Wireframe — View → Wireframe (W).

نور Light

نور اصلی یک لامپ قابل‌جابه‌جایی است:

The key light is a movable bulb:

  • نمایش ← تنظیمات نور… (L) — اسلایدرهای X / Y / Z و قدرت، و «نمایش لامپ».
  • نمایش ← جابه‌جایی نور — پیش‌تنظیم‌های سریع (جلو، عقب، بالا، چپ، راست، پیش‌فرض).
  • کشیدن لامپ در نما وقتی لامپ دیده می‌شود (نمایش لامپ، B).
  • View → Light settings… (L) — X / Y / Z and strength sliders, plus “Show bulb”.
  • View → Move light — presets (front, back, top, left, right, default).
  • Drag the bulb when it is visible (Show bulb, B).
در سطوح کیفیت بالاتر، سایه از لامپ پیروی می‌کند — با جابه‌جایی لامپ جهت سایه عوض می‌شود. At higher levels, shadows follow the light — move the bulb to change shadow direction.

کیفیت و ظاهر Quality & look

کیفیت رندر Render quality

نمایش ← کیفیت رندر

View → Render quality

سطحمناسب برای LevelBest for
سطح ۱ — استانداردپیش‌نمایش سریع، مدل‌های بزرگ، موبایل Level 1 — StandardFast preview, big models, phones
سطح ۲ — پیشرفتهظاهر نرم‌تر + سایه (با کیفیت Path) Level 2 — EnhancedSofter look + shadows (with path quality)
سطح ۳ — سینمایینور کلیدی + سایه دنبال لامپ Level 3 — CinematicKey light + shadows that follow the bulb
سطح ۴ — فوق‌العادهنور و متریال قوی‌تر (سنگین‌تر) Level 4 — UltraStronger light and materials (heavier)

کیفیت Path Path quality

نمایش ← کیفیت Path هزینهٔ سایه و وضوح را تنظیم می‌کند.

View → Path quality controls shadow cost and resolution.

تنظیمنتیجه SettingWhat you get
خاموش (سریع‌ترین)بدون سایه — روان‌ترین Off (fastest)No shadows — smoothest FPS
کمسایه سبک — پیش‌فرض موبایل LowLight shadows — phone default
متوسطمتعادل — پیش‌فرض رایانه MediumBalanced — PC default
زیادسایه تیزتر — هزینهٔ بیشتر HighSharper shadows — more GPU cost
  • درخشش (E) — بازتاب محیط روی متریال‌ها.
  • متریال شیشه (G) — ظاهر شیشه برای قطعاتی مثل شیشه / پنجره.
  • Shine (E) — environment reflections on materials.
  • Glass materials (G) — glass look on parts like glass / window.
اگر کند است، کیفیت Path را روی کم یا خاموش بگذارید و سطح ۱ یا ۲ را انتخاب کنید. If it lags, set Path quality to Low or Off, and use Level 1 or 2.

اشیای صحنه و کولیدر Scene objects & colliders

بعد از بارگذاری مدل، از نمایش ← اشیای صحنه (یا دکمهٔ پیام پایین صفحه) لیست مش‌ها، نورها، نقاط و کولیدرها را ببینید.

After a model loads, use View → Scene objects (or the toast action) to list meshes, lights, points, and colliders.

  • قطعاتی که در نامشان «coll» دارند به‌عنوان کولیدر مخفی شروع می‌شوند (در خروجی فایل می‌مانند).
  • با چک‌باکس هر مورد را روشن یا خاموش کنید.
  • Parts with “coll” in the name start hidden as colliders (still in export).
  • Use the checkboxes to show or hide each item.

ذخیره و تبدیل Save & convert

  • فایل ← ذخیره تصویر (PNG) (Ctrl+S) — تصویر نمای فعلی.
  • منوی تبدیل — خروجی به فرمت‌های دیگر در صورت موجود بودن.
  • خروجی همهٔ فرمت‌ها (ZIP) — چند خروجی در یک زیپ.
  • فایل ← بستن مدل — پاک کردن نما.
  • File → Save image (PNG) (Ctrl+S) — screenshot of the view.
  • Convert menu — export to other formats when available.
  • Export all formats (ZIP) — several outputs in one zip.
  • File → Close model — clear the viewport.

زبان برنامه App language

در خود Renderer از منوی زبان بین فارسی و انگلیسی جابه‌جا شوید. پیام‌های پایین صفحه هم با همان زبان هماهنگ می‌شوند.

In the app, switch Persian / English from the Language menu. Status messages follow the same language.

نکته‌ها Tips

روی موبایل

On phones

کیفیت Path را کم یا خاموش بگذارید. منوهای تو در تو به‌صورت پنل تمام‌عرض باز می‌شوند.

Use Path quality Low/Off. Nested menus open as a full-width panel.

روی رایانه

On PC

با رفتن موس روی منو، زیرمنوها باز می‌شوند (تبدیل، کیفیت، پیش‌تنظیم نور).

Hover menus to open submenus (Convert, quality, light presets).

عکس بهتر

Better screenshots

کیفیت را بالا ببرید، نور را تنظیم کنید، درخشش را روشن کنید، سپس PNG ذخیره کنید.

Raise quality, place the light, enable Shine, then Save PNG.
